# 🛍️ ClickStore — Modern E-Commerce Frontend

### Shop More. Live Better.

A modern, responsive e-commerce web application frontend built with **React.js, JavaScript, HTML, and CSS**. ClickStore provides a clean shopping experience with product discovery, category navigation, search, wishlist, shopping cart, and a dedicated interface for interacting with backend services.

[🚀 View Repository](https://github.com/rahulbhadekar/ClickStore-Frontend) · [👨‍💻 Developer](https://github.com/rahulbhadekar)


## ✨ Key Features

- 🏠 **Modern Homepage** — Clean layout with an animated promotional hero banner.
- 🔍 **Product Search** — Search interface for discovering products.
- 🗂️ **Category Navigation** — Browse products across different categories.
- ❤️ **Wishlist** — Interface for saving favourite products.
- 🛒 **Shopping Cart** — Add and manage products before checkout.
- 🔥 **Deals & New Arrivals** — Dedicated navigation for shopping collections.
- 📦 **Product Listings** — Product cards with pricing and product images.
- 👤 **Account Interface** — User account and authentication interface.
- 🛍️ **Checkout Experience** — Frontend checkout workflow.
- 🧑‍💼 **Seller & Admin Interfaces** — Dedicated screens for seller and administrative workflows.
- 📱 **Responsive Design** — Designed to provide a smooth experience across different screen sizes.

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the repository

```bash
git clone https://github.com/rahulbhadekar/ClickStore-Frontend.git
cd ClickStore-Frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal. Vite commonly uses:

```text
http://localhost:5173
```

### 4. Build for production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🔗 Backend Integration

ClickStore's frontend is designed to communicate with a Java Spring Boot backend through REST APIs.

**Backend repository:** [ClickStore-Backend](https://github.com/rahulbhadekar/ClickStore-Backend)

The complete application uses a backend stack that includes Java, Spring Boot, MySQL, Spring Data JPA, and JWT-based authentication.

Before running the integrated application, ensure that the backend is running and the frontend API configuration points to the correct backend URL.

For local development, the backend may use:

```text
http://localhost:8080
```

For deployment, configure the appropriate production API URL instead of relying on localhost.
